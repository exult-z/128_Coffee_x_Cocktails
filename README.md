# 1.28 Coffee x Cocktails

## Project Overview
This website was developed by our group as part of our Web Development course. It showcases the menu, cocktail bar reservations, events, and contact information of 1.28 Coffee x Cocktails a cozy neighborhood café in Paco, Manila by day, and a reservation-only cocktail bar by night.

## Purpose
To provide an online presence for 1.28 Coffee x Cocktails, promote its day-to-night café-and-bar concept, and allow customers to explore the menu and reserve cocktail bar slots directly through the site.

## Site Structure
- `index.html` – Homepage (featured picks, bestsellers, events)
- `menu.html` – Full menu with live search & category filter
- `reservations.html` – Cocktail Bar reservation form (18+)
- `reviews.html` – Customer reviews & ratings
- `contact.html` – Contact form + embedded Google Map
- `admin.html` – Admin Dashboard (localStorage-backed CMS, login-protected)
- `assets/` – Images, icons, logo
- `css/` – Stylesheets
- `js/` – JavaScript modules
- `data/` – Seed data (menu, events, reviews)

## Design Concept
- **Color Scheme**: Warm café tones (cream, mocha, amber) by day; moody charcoal and gold accents for the cocktail bar theme
- **Typography**: Sans-serif body for readability, elegant serif headings for a sophisticated night vibe
- **Layout**: Consistent spacing, mobile-first responsive grid

## Key Features
- Interactive menu with live search and category filter
- Featured picks + bestsellers ribbon on the homepage
- Cocktail Bar reservation form (18+ age verification, day-of-week restriction, max 8 guests)
- Customer reviews with rating system
- Contact form + embedded Google Map
- Events & promotions showcase
- Photo gallery
- Social media integration
- Admin Dashboard (localStorage-backed CMS) for managing menu, promotions, events, reservations, reviews, and inquiries
